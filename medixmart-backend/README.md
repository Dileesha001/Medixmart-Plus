# Medixmart backend

Folder scaffold for the Node.js/Express REST API and PostgreSQL integration. No server or dependencies have been initialized yet.

The root will contain `server.js`, `package.json`, and a safe `.env.example` after backend initialization. Keep the real `.env` untracked. Put SQL scripts under `src/sql`, including the planned `01_create_tables.sql` and `02_dummy_data.sql` when implemented.

See the [folder guide](../docs/folder-structure.md) and [project overview](../docs/project-overview.md) before adding routes, services, or database logic.
