# Medixmart Flutter app

Folder scaffold for a shared Flutter/Dart client targeting Windows and Android. The Flutter project and its SDK-generated platform files have not been initialized yet.

The blueprint specifies Provider for state management, a central authenticated API service, and reusable widgets. Screens are grouped by pharmacy workflow. Initialize Flutter here with Windows and Android platform support before adding application code, and preserve the existing directory guide and scaffold.

See the [folder guide](../docs/folder-structure.md) and [project overview](../docs/project-overview.md) for responsibilities and requirements.
